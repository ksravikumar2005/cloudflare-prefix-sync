# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. Everyone taking part in issues, pull requests, discussions and other project spaces is expected to follow it.

In short: be respectful, assume good intent, give and accept constructive feedback, and keep discussion focused on the work. Harassment, personal attacks and discriminatory language are not acceptable.

## Reporting

Report unacceptable behavior to the maintainers privately, by email to the address in the repository's GitHub profile or through a private GitHub security advisory if no email is listed. Reports are handled confidentially. Maintainers may remove content and restrict or ban participants who break this code, following the enforcement guidelines of the Contributor Covenant.
